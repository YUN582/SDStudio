# 원본 5.8.1 반영 내용

2026년 11월 26일, [제작자의 SDStudio](https://github.com/Dd154663/SDStudio) 5.8.1의 변경을 [개인 수정본](https://github.com/YUN582/SDStudio)에 반영했습니다. Gemini가 작업 방향과 검토를 맡고 Codex가 수정·검증했습니다. **소스와 검토용 패키지를 준비한 상태이며, 사용 중인 설치본은 교체하지 않았습니다.**

## 추가하고 고친 것

- **캡처:** 여러 이미지를 한 장으로 모아 저장합니다. 씬 목록의 `더보기 → 캡처`, 이미지 목록의 다운로드 옆 캡처 아이콘에서 엽니다. 이미지 선택·즐겨찾기·현재 목록을 고를 수 있고, 원본뿐 아니라 연결된 인페인트·I2I 결과도 포함합니다. PNG가 기본입니다.
- **씬 이미지·편집 전환:** 창 위에서 두 화면을 전환합니다. 선택 중에도 씬 이름이 표시되고, 편집창에서 Esc를 누르면 이전 이미지 목록으로 돌아갑니다.
- **안전한 키 조작:** 캡처 창을 조작하는 동안 뒤쪽 씬의 단축키가 생성 예약·씬 열기를 실행하지 않도록 막았습니다. 인페인트 편집창에서 생성 바가 두 개 표시되는 문제도 정리했습니다.
- **마스크 저장:** 저장 직후 닫았다가 다시 열어도 저장을 기다린 뒤 마스크를 읽습니다. 검토 중 발견한 중복 저장·다른 씬으로 마스크가 넘어갈 가능성도 보완했습니다.
- **레퍼런스:** V4.5와 V5의 기본값을 나눠 기억하고, 모델에 맞는 종류·강도를 표시합니다. 비용 안내와 업로드 직후 썸네일 표시를 반영했습니다.
- **모바일:** 갤러리 등록·이미지 경로·썸네일 관련 수정을 받고, 키보드가 닫혔는데 프롬프트 도구가 남는 문제를 보완했습니다.
- **가져온 이미지 활용:** 생성 정보가 없어도 분석이 끝나며, 같은 창에서 바이브·레퍼런스 추가와 I2I 편집으로 이어집니다. I2I 편집은 작업을 열며 생성 예약을 자동으로 넣지 않습니다.

캡처에서 이미지 목록은 화면의 정렬·필터·선택 순서를 따릅니다. 씬 캡처의 `최근 생성`은 최신순이며, `즐겨찾기`는 해당 씬의 표시 순서를 따릅니다. 두 방식 모두 씬마다 ‘한 줄의 장수’까지만 담습니다.

## 기존 수정본에서 유지한 것

작업별 입력본·마스크 저장 위치, 프로젝트 단위 캐시·휴지통, 변형 결과의 즐겨찾기와 수동 순서, 단일 이미지의 조합 1개만 가져오는 편집 흐름, 기존 상세 보기와 라이브러리 디자인을 유지했습니다. 없앴던 입력칸 내부 찾기는 되살리지 않았으며, 확대 창의 찾기·바꾸기를 계속 사용합니다.

이번 5.8.1 반영 자체가 프로젝트 저장 구조를 새로 바꾸지는 않습니다. 수정본이 이전부터 사용하던 저장 구조와 원본의 차이는 여전히 있으므로, 제작자의 원본에 기능을 가져갈 때에는 별도 검토가 필요합니다.

## 확인한 범위

- 타입 검사와 메인·화면 배포 빌드 통과.
- 저장·복원·예약·프롬프트·내보내기 핵심 검사 **676개 통과**.
- 캡처·레퍼런스·모바일 도구 등 관련 검사 **111개 통과**.
- 전체 검사는 **4,507개 통과, 126개 실패**입니다. 통합 전에 실패했던 항목과 하나씩 대조했으며 **새로 생긴 실패는 없습니다.**
- 인터넷을 차단한 별도 Windows 앱에서 합성 이미지로 캡처 PNG의 실제 내용·순서, 변형 즐겨찾기, 모델별 레퍼런스 값, 마스크 저장 직후 재열기를 확인했습니다. 개인 프로젝트나 유료 생성은 사용하지 않았습니다. 총 13개 실제 앱 점검을 통과했습니다.

Android 실기기, macOS, 실제 유료 생성은 확인하지 않았습니다. 기존 검사 실패도 이번 작업에서 모두 고친 것은 아닙니다.

Gemini의 최종 재검토에서 추가 차단 문제가 없음을 확인했습니다. 설치본은 검토 전 상태로 유지합니다.
