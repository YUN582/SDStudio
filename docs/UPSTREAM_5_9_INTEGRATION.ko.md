# SDStudio 5.9 반영 내용

2026-11-28. 본가 `17044ed`까지 반영. 이전 기준은 5.8.1 `31e5e8e`, 수정 전 포크는 `f44ae6e`.

## 사용할 수 있게 된 기능

- 히스토리를 최근 200장까지 보관. 큰 격자로 열고 즐겨찾기·현재 프로젝트로 걸러 볼 수 있다.
- 씬 목록에 씬별 이미지, 가로 줄, 최신순 보기를 추가. 기존 씬 카드 보기가 기본이다.
- 히스토리를 세로로 이어 볼 수 있다. 이미지를 누르면 기존 상세 보기로 열린다. 한 장 보기의 방향키·스와이프로 같은 히스토리 목록을 탐색한다.

## 우리 버전에 맞춘 부분

- 새 씬 보기에도 연결된 인페인트·I2I 결과를 포함한다. 같은 파일명이 있어도 경로로 구분한다.
- 즐겨찾기·삭제·편집 메뉴는 해당 이미지가 실제로 속한 작업을 대상으로 한다.
- 한 장 상세 보기는 기존 공통 화면을 유지한다. 메타정보·복사·편집·이미지 변형 기능과 히스토리 드래그를 유지한다.
- 기존 씬 카드와 이미지 그리드의 선택·방향키·드래그 기능을 유지한다. 새 이미지 보기는 본가처럼 이미지 탐색용이며, 씬 복수 선택·순서 변경은 씬 카드 보기에서 한다.
- 프리셋별 모델, 작업 하나의 조합만 예약하는 동작, 예약 시 해상도 고정, 작업별 저장 폴더를 유지한다.

## 확인한 범위

- 타입 검사와 화면 빌드 성공.
- 관련 자동 검사 22묶음 276항목 통과. 보기 전환 시 숨은 선택 제거, 히스토리 삭제 후 단축키 잠금 해제도 포함한다.
- 별도 시험 앱에서 88개 씬과 200개 히스토리로 10개 동작 검사 통과. 실제 프로젝트·생성 API는 사용하지 않았다.
- 추가 UI 검사에는 수정 전에도 실패하던 20항목이 그대로 남아 있다. 이번 변경에서 새로 실패한 항목은 없다.
- 시험 환경에서 화면 캡처용 표시 화면을 얻지 못했다. 실제 클릭·키 입력과 화면 배치 수치는 확인했으며, 최종 외관은 설치 후 사용자 화면에서 확인해야 한다.

설치본과 개인 데이터는 교체하지 않았다. 예전 버전으로 돌아가면 히스토리 목록은 그 버전의 상한인 30장으로 줄 수 있다. 이미지 파일은 지워지지 않는다.
