비교 기준: 2026-11-25. 원본 `Dd154663/SDStudio`의 `d95c674`와 개인 수정본 `YUN582/SDStudio`의 `c3b29d4`를 비교했습니다. 원본에 새로 쌓인 변경 기록은 63개, 직접 겹친 파일은 55개였습니다.

## 추가 검토에서 확인한 오류

아래 내용은 통합 뒤 Gemini와 다시 검토한 결과입니다. 실패한 검사를 전부 화면 차이로 설명할 수는 없습니다.

- 이미지 우클릭 메뉴에 같은 기능이 두 번 나오거나, 메뉴와 실제 동작이 연결되지 않은 항목이 있었습니다.
- 새 창 헤더를 넣는 처리가 만들어져 있었지만 실제 창에서는 사용하지 않았습니다.
- 일부 예약 메뉴가 앱 테마 밖에 표시되고, 외부 편집기 실행에 실패해도 파일 감시가 남았습니다.

수정 소스에서 메뉴 동작·헤더 연결·겹친 창의 키보드 활성 상태·예약 메뉴를 대상으로 47개 검사를 통과했습니다. **이 후속 수정은 아직 설치하지 않았습니다.** 이미지 상세 보기 개편은 Gemini가 만든 별도 시안으로 먼저 검토합니다. 이 부분 검증이 기존 전체 검사 실패 126개를 모두 해결했다는 뜻은 아닙니다.

## 통합 당시 남겨 둔 부분

새 원본과 네 버전이 같은 기능을 다른 화면으로 구현한 곳은 네 버전의 화면을 기준으로 두었습니다. 이미지 상세창 전체 배치와 새 상세 정보 접기 UI, 별도의 보기 순서 선택 UI는 통째로 교체하지 않았습니다. 크게 편집하는 창, 실제 저장 순서를 바꾸는 즐겨찾기·최신순 정렬, 이미지 그리드 끌기·선택을 유지했습니다. 화면 차이에 따른 검사 실패와 실제로 연결이 누락된 기능을 따로 확인해야 합니다. 상세 보기의 새 구성을 앞으로도 제외하기로 확정한 것은 아닙니다.

특히 폴더 구조를 원본 방식으로 되돌리지 않았습니다. 기존 프로젝트와 중첩 인페인트·I2I 작업, 작업별 vibes, 프로젝트 단위 휴지통·캐시는 네 수정본의 규칙을 유지합니다. 원본 버전으로 되돌아갈 때까지 호환된다는 뜻은 아닙니다.
